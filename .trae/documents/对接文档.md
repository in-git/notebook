# 前端C端登录对接精简文档（开发对接专用，剔除冗余描述，直接给开发/AI生成代码）

## 一、三种登录方式入参

### 1.账号密码登录 `/auth/c/doLogin` POST

| 参数           | 必填 | 说明                                  |
| -------------- | ---- | ------------------------------------- |
| account        | 是   | 账号                                  |
| password       | 是   | **前端SM2加密后字符串，禁止明文传输** |
| validCode      | 条件 | 验证码开关开启则必填                  |
| validCodeReqNo | 条件 | 验证码接口返回请求号，开启验证码必填  |
| tenCode        | 条件 | 多租户启用时必填                      |

逻辑要点：

1. 页面加载读取`REMEMBER_ACCOUNT`回填账号；仅保存账号，不存密码
2. 登录失败且验证码开启 → 主动刷新图形验证码

### 2.手机号验证码登录 `/auth/c/doLoginByPhone` POST

| 参数           | 必填 | 说明                   |
| -------------- | ---- | ---------------------- |
| phone          | 是   | 11位手机号正则校验     |
| validCode      | 是   | 6位短信验证码          |
| validCodeReqNo | 是   | 获取验证码接口返回编号 |

前置接口：`/auth/c/getPhoneValidCode` GET，传phone，触发60s倒计时

### 3.邮箱验证码登录 `/auth/c/doLoginByEmail` POST

| 参数           | 必填 | 说明         |
| -------------- | ---- | ------------ |
| email          | 是   | 邮箱格式校验 |
| validCode      | 是   | 邮箱验证码   |
| validCodeReqNo | 是   | 请求编号     |

前置接口：`/auth/c/getEmailValidCode` GET，传email

## 二、验证码接口

图形验证码 `getPicCaptcha` GET
返回：base64图片、validCodeReqNo

## 三、SM2加密（固定实现）

公钥固定

```js
import smCrypto from 'sm-crypto';
const publicKey =
  '04298364ec840088475eae92a591e01284d1abefcda348b47eb324bb521bb03b0b2a5bc393f6b71dabb8f15c99a0050818b56b23f31743b93df9cf8948f15ddb54';
// 调用：doEncrypt(原始密码)，输出hex字符串作为password参数
smCrypto.sm2.doEncrypt(msg, publicKey, 1);
```

## 四、登录成功后置统一方法 afterLogin

1. 存储 `CLIENT_TOKEN`（请求拦截器自动放入Authorization）
2. 调用 `/auth/c/getLoginUser` GET 获取用户信息，存入 `CLIENT_USER_INFO`
3. 路由跳转 `router.replace('/front/client/index')`
   > 使用replace，禁止push，防止浏览器回退到登录页

## 五、本地存储规范（tool.data封装localStorage）

| key              | 作用                             |
| ---------------- | -------------------------------- |
| CLIENT_TOKEN     | C端鉴权凭证，区分后台管理端token |
| CLIENT_USER_INFO | 登录用户信息                     |
| REMEMBER_ACCOUNT | 勾选记住我，仅存放账号字符串     |

## 六、登出逻辑

调用 `/auth/c/doLogout` GET
清除：CLIENT_TOKEN、CLIENT_USER_INFO；保留REMEMBER_ACCOUNT

## 七、表单校验规则

手机号正则：`/^(13[0-9]|14[579]|15[0-3,5-9]|16[6]|17[0135678]|18[0-9]|19[89])\d{8}$/`
邮箱正则：`/^[a-zA-Z0-9_-]+@[a-zA-Z0-9_-]+(\.[a-zA-Z0-9_-]+)+$/`

## 八、关键约束（硬性，必须遵守）

1. 所有登录密码**必须前端SM2加密**，严禁明文
2. validCodeReqNo必须和验证码配套传递，前后一致
3. 验证码开关`captchaOpen`由系统配置接口获取，禁止硬编码
4. 短信/邮箱获取验证码按钮自带60s倒计时防重复点击
5. C端接口统一前缀 `/auth/c/`
